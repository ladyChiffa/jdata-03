# Состав проекта

Для корректной сборки нужно синхронизировать и перезагрузить maven projects, 
иначе версии ломбока подхватываются кривые и не создается корректной инициализации final полей.
Ну и вообще странно аннотации работают.

## ветка main

Основное ДЗ - контроллер, который работает с БД.
Реализация в PersonRepository использования EntityManager'а с указанием запросов, которыми EntityManager оперирует.

## ветка em-examples

Примеры применения EntityManager для сохранения в БД минуя явно заданные запросы - через то, что EM оперирует объектами Entity и автоматически генерирует SQL.

Примеры даются в методе, который запускается при старте сервиса.
Все закомментированы, чтобы не мешали друг другу.
Также пример применения аннотации @Transactional.

## ветка jpa-repository

Здесь реализовано два куска функционала (неудачное решение, надо было в разных ветках)

1. Превращение репозитория PersonRepository в JPA-репозиторий.
   При этом в репозитории сразу появляются методы CRUD,
   и мы их дополняем автогенерируемыми методами интерфейса.

2. добавление ограничения доступа к разным ручкам - класс SecurityConfiguration.
